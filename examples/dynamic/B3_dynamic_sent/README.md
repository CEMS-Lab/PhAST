# B3 Dynamic SENT

Dynamic single-edge-notched tension smoke/example. The YAML is runnable and the
folder includes lightweight CSV and PNG outputs from the current curated SENT
result.

Run:

```bash
python -m phast run examples/dynamic/B3_dynamic_sent/config.yaml
```

Release note: the current config is useful as a dynamic smoke example. Treat it
as qualitative unless a finer public result is promoted.

Expected public visuals are `initial_conditions.png`, `thumbnail.png`,
`damage_multipanel.png`, and the CSV history/energy files.
